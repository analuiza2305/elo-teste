# 💜 Elomaterno  
### **Conectando, acolhendo e fortalecendo mães solo**

---

## 📝 Sobre o Projeto

O **Elomaterno** é um projeto desenvolvido como **Trabalho de Conclusão de Curso (TCC)**, com o objetivo de criar uma **rede de apoio digital para mães solo**, promovendo acolhimento, informação, orientação e conexão.

A plataforma oferece um ambiente seguro e acessível, onde mães solo podem encontrar **suporte emocional, troca de experiências e conteúdos relevantes**, contribuindo para o fortalecimento social e emocional dessas mulheres.

---

## 🎯 Objetivos

- Criar uma rede de apoio para mães solo  
- Promover acolhimento e empatia por meio da tecnologia  
- Facilitar o acesso à informação e orientação  
- Incentivar a troca de experiências entre usuárias  
- Fortalecer o empoderamento feminino
